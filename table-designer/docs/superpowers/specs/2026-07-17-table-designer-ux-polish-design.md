# Table Designer 体验打磨设计说明

日期：2026-07-17  
状态：已实现（沟通向体验打磨）  
前置：`2026-07-16-table-designer-design.md`（第一版能力）

## 1. 产品定位与原则

### 一句话定位

Table Designer 是 SuSy 表格重构的**沟通样机**：用来和设计/开发对齐「看起来对不对」，不是工程配置器，也不是规范库。

### 使用目的

在评审或一对一对齐时，快速演示：某张业务表在桌面 / 平板 / 手机下的密度、字体、留白、列宽与截断是否可接受。

### 三条原则

1. **观感优先于数字** — 预览要「像页面」；右侧元数据服务讲解，不喧宾夺主。
2. **表达力刚好够演完场景** — 补字体、间距，使密/疏、大字/小字能演出来；不借机扩成完整设计系统。
3. **对齐成本最低** — 别人 30 秒内能看懂你在论证什么；少术语、少面板噪音。

### 产品角色选择

本轮定位为 **沟通媒介（C）**：对齐预期为主，数字精确度为辅。

### 本轮明确不做

- 导出 JSON / CSS / 工程配置
- 多方案本地保存与对比库
- 列类型 / 组件库 / 复杂规范校验

上述属于「规范样机 / 交付闭环」定位，待产品角色升级后再议。

## 2. 优化路径选择

在「体验打磨、不扩定位」前提下，采用 **观感对齐优先**（方案 1），并以 **均衡小迭代** 覆盖：

- 预览真实感
- 交互顺手度
- 信息可读性
- 响应式可讲解性（非像素级工程精度）

备选已排除：

- 决策沙盘化：会把产品拉回「对数字拍板」，偏离沟通媒介定位。
- 轻量规范样机：过早沉淀规范，降低沟通弹性。

## 3. 本轮改什么（按沟通场景）

| 要对齐的话 | 对方要看见什么 | 本轮支撑 |
|---|---|---|
| 「字别太小 / 别太大」 | 改字号后疏密观感立刻变化 | 字体族 + 字号可调（全局；单列可覆盖字号） |
| 「行太挤 / 太松」 | 同样列宽下疏密一眼不同 | 行高 / 单元格内边距（间距）可调 |
| 「这列在窄屏会怎样」 | 断点或拖容器时截断/滚动清楚 | 保留断点与拖宽；状态提示更口语 |
| 「列宽这样摆是否舒服」 | 拖列宽即时反馈，不挡讲解 | 保留拖列宽；减少误触、编辑更稳 |
| 「用真实文案再看一眼」 | 改单元格后仍像产品表 | 保留可编辑；编辑态不破坏「像页面」 |

### 配置结构（刻意保持简单）

- **全局**：字体族、默认字号、间距（行高 / 内边距）、既有行列数、默认列宽、固定/自适应、截断、表头加粗等
- **单列覆盖**：列名、列宽、固定/自适应、字号、截断（未覆盖继承全局）
- **间距**：仅全局（够演疏密）；不做每列不同内边距

### 四面均衡如何落地（仍服务沟通）

1. **预览真实感** — 字体、间距进入预览；整体更接近业务页表格，而非调试画布。
2. **交互顺手** — 拖列宽 / 拖容器 / 点选编辑边界更清晰，讲解时不易手滑。
3. **信息可读** — 右侧从参数列表改为讲解辅助：先结论（是否溢出、是否偏挤），数字作附注。
4. **响应式可讲解** — 不追求像素级工程精度；追求切换断点时对方能稳定复现你描述的现象。

## 4. 成功标准

1. **5 分钟能讲完一张表** — 一次对齐里可演示字体疏密、间距松紧、列宽、桌面→手机变化，对方无需先学工具。
2. **对方用观感语言反馈** — 「太挤 / 字偏小 / 窄屏标题截太狠」，而不是卡在「这个 px 对不对」。
3. **场景可演全** — 字体 + 间距 + 既有列宽/截断/断点，覆盖常见对齐场景，不必再靠截图或口头补洞。
4. **工具不抢戏** — 视线在中间预览；左右面板是辅助，不迫使大家盯参数表。

### 验收口头标准

拿真实业务表文案进预览 → 调字体与间距 → 切 1440 / 768 / 375 → 对方能明确说「可以按这个感觉做」或「哪里要改」——即过关。

## 5. 风险与边界

| 风险 | 为何警惕 | 本轮收法 |
|---|---|---|
| 被当成准生产配置器 | 定位被拉去追导出/精度 | 不做导出；元数据只服务讲解 |
| 参数越加越多 | 样机变控制台 | 间距仅全局；字体族选项克制（少量常用） |
| 「像真表」过度还原 | 陷入组件细节 | 只还原影响观感判断的层：字、疏密、列宽、截断 |
| 数字与观感打架 | 右侧堆宽度干扰对齐 | 右侧先结论后数字；预览内不显示调试元数据 |

## 6. 与第一版关系

第一版已具备：三栏工作台、全局+单列覆盖、断点（1440/768/375）、容器拖宽、列宽拖拽回写、单元格可编辑、元数据面板。

本轮是在**同一产品壳**内做沟通向体验打磨与表达力补齐（字体、间距），不改变「沟通样机」定位，不升级为交付/规范工具。

# Table Designer 设计说明

日期：2026-07-16  
状态：已确认，进入实现

## 目标

为 SuSy 多页面表格重构提供可视化设计工具：配置表格元数据，实时预览样式与响应式表现，并展示当前生效的列宽等元数据。

## 布局

三栏工作台：

1. **左栏**：全局默认配置 + 按列覆盖
2. **中栏**：断点切换（桌面 1440 / 平板 768 / 手机 375）+ 可拖宽预览容器 + 实时表格
3. **右栏**：当前生效元数据（总宽、各列实际宽度、固定/自适应、字号、截断）

## 配置模型

- 全局：行数、列数、默认列宽、是否固定宽度、字号、是否截断、表头加粗
- 单列覆盖：列名、列宽、固定/自适应、字号、截断；未覆盖项继承全局
- 响应式：断点预设 + 拖动容器宽度，元数据反映当前容器下的实际列宽

## 第一版范围

- 做：实时预览、元数据面板、断点与拖宽
- 不做：导出 JSON/CSS、本地多方案保存、拖拽改列宽回写

## 风险

- 列数过多时左侧配置变长，默认 4–6 列
- 固定列过多时窄屏出现横向滚动，属预期行为
